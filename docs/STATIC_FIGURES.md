# Static Scientific Figure Export and DOCX Embedding

PyAutoStat supports optional publication-quality static scientific figure export
(PNG, SVG, and standalone figure-PDF) and native figure embedding in editable
Microsoft Word (`.docx`) research reports.

This capability renders directly from the existing immutable `FigureSpec` layer.
It preserves all scientific and statistical safeguards:
- **No recalculation:** Figures are rendered strictly from stored, authoritative
  estimates and confidence intervals. No inferential re-fitting or p-value ranking occurs.
- **No raw data access:** Figures never touch raw DataFrame rows, preventing
  accidental data leakage.
- **Deterministic and reproducible:** Every figure artifact retains exact placement,
  labels, bounds, and neutral reference lines.
- **Editable reports:** In Word export, figures are embedded as high-resolution PNGs
  while text, tables, and statistics remain fully editable OpenXML.

---

## 1. Installation and Chrome Setup

Static figure export requires the optional `figures` dependency set:

```bash
pip install "pyautostat[figures]"
```

PyAutoStat relies on modern **Kaleido v1+**, which drives a headless Chrome or
Chromium browser instance to render vector (SVG, PDF) and raster (PNG) graphics.

To install a compatible browser, run the official Plotly helper (use `-y` for non-interactive automation):

```bash
plotly_get_chrome -y
```

> **Important:** PyAutoStat **never** downloads browsers or binary dependencies
> automatically during library calls or module imports. If Chrome is not installed,
> PyAutoStat provides clear, actionable instructions. Base PyAutoStat workflows
> and text/HTML/DOCX reports remain completely functional without Kaleido or Chrome.

## 2. Public Static Figure APIs

PyAutoStat provides two top-level functions for static figure generation:
`to_static_figures` and `save_static_figures`.

```python
from pyautostat import to_static_figures, save_static_figures

# In-memory rendering
figures = to_static_figures(
    workflow_or_report,
    format="png",          # "png", "svg", or "pdf"
    detail="standard",     # "compact", "standard", or "full"
    scale=2.0,             # Resolution multiplier (e.g. 2.0 for Retina/print)
)

# Direct file export with collision safety
saved_paths = save_static_figures(
    workflow_or_report,
    "output/figures/",
    format="svg",
    overwrite=False,       # Preflights and prevents accidental overwrites
)
```

### Return Model: `StaticFigureArtifact`

`to_static_figures` returns a tuple of immutable `StaticFigureArtifact` records:

```python
@dataclass(frozen=True)
class StaticFigureArtifact:
    index: int                  # 1-based sequential figure index
    kind: str                   # e.g. "estimate_ci", "forest", "count_heatmap"
    title: str                  # Scientific title from FigureSpec
    placement: str              # Canonical placement ('key_results', 'coefficients', 'pairwise', 'contingency', 'cell_summary')
    format: str                 # "png", "svg", or "pdf"
    data: bytes                 # Raw binary payload
    filename: str               # Library-controlled safe filename (e.g. "figure_01_estimate_ci.png")
    width: int | None = None    # Width in pixels
    height: int | None = None   # Height in pixels
```

## 3. Supported Formats and Differences

| Format | Extension | Primary Use Case | Output Characteristics |
| :--- | :--- | :--- | :--- |
| **PNG** | `.png` | Presentations, Word embedding, Web | High-resolution raster (scale=2.0 default), verified PNG signature `\x89PNG\r\n\x1a\n` |
| **SVG** | `.svg` | Journal submissions, vector editing | Clean UTF-8 XML `<svg>`, protected against script and event-handler injection |
| **PDF** | `.pdf` | Vector print, camera-ready submission | Standalone single-page vector figure starting with `%PDF` |

> **Figure-PDF vs Full-Report PDF:**
> A figure-PDF generated by `to_static_figures(..., format="pdf")` is a standalone,
> single-page vector rendering of the scientific graphic. It is distinct from
> `to_pdf(...)`, which produces a multi-page comprehensive research report document
> via Playwright.

---

## 4. Dimension and Scale Policies

Dimensions are governed by centralized scientific defaults based on the figure kind:
- **Estimate / CI plots:** 1,000 x 550 px
- **Forest plots:** Dynamic height based on coefficient/contrast rows (~35 px per row + margins)
- **Heatmaps:** Proportional to row and column counts
- **Profiles:** 1,000 x 600 px

Users can customize dimensions while protected by safety limits:
- `width` and `height`: Must be positive integers up to 10,000 px (booleans rejected).
- `scale`: Must be a positive finite number up to 8.0.

## 5. Optional DOCX Figure Embedding

PyAutoStat supports embedding static PNG figures directly into editable Word documents:

```python
from pyautostat import to_docx, save_docx

# By default, include_figures is False (no Kaleido/Chrome requirement)
docx_bytes = to_docx(workflow, include_figures=True)

# Save with figures
save_docx(
    workflow,
    "research_report.docx",
    include_figures=True,
    title="Customer Spend Drivers Analysis",
    style="apa",
    overwrite=True,
)
```

### DOCX Placement and Captions
- **Placement:** Figures are placed near their relevant semantic sections (`key_results`,
  `coefficients`, `pairwise`, `contingency`, `cell_summary`).
- **Captions:** Each embedded image is paired with a numbered, editable caption styled
  with `PyAutoStat Figure Caption` (e.g. `Figure 1. Coefficient estimates and 95% confidence intervals.`).
- **Responsive Sizing:** Images automatically scale to the printable width of the document
  accounting for page size (A4 / Letter), orientation (portrait / landscape), and margins.

## 6. Research Bundle Integration

Static scientific figures can also be bundled into integrity-verifiable research ZIP packages:

```python
from pyautostat import to_bundle, save_bundle

bundle_bytes = to_bundle(
    workflow,
    formats=["html", "docx", "json", "csv"],
    include_figures=True,            # Controls figures embedded inside HTML, PDF, and DOCX reports
    include_static_figures=True,     # Packages standalone figure files into pyautostat_bundle/figures/
    static_figure_format="png",      # "png", "svg", or "pdf"
)
```

When enabled, standalone figures are stored under `pyautostat_bundle/figures/`
with the manifest role `"scientific_figure"`, and their exact byte sizes and SHA-256
digests are verified by `verify_bundle`.
